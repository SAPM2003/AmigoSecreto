#  Proyecto: Amigo Secreto

¡Bienvenido al sorteador de **Amigo Secreto**! Esta es una aplicación web sencilla y funcional desarrollada como parte de un desafío de lógica de programación. El objetivo es permitir que los usuarios ingresen nombres de amigos en una lista y realicen un sorteo aleatorio para determinar quién es el "amigo secreto".

##  Funcionalidades

- **Agregar nombres:** Interfaz intuitiva para escribir y añadir nombres a la lista.
- **Validación:** El sistema impide agregar campos vacíos mediante alertas interactivas.
- **Visualización dinámica:** Los nombres aparecen en tiempo real en una lista visible en pantalla.
- **Sorteo aleatorio:** Algoritmo que selecciona un ganador al azar y lo muestra de forma destacada.

##  Tecnologías utilizadas

* **HTML5:** Estructura semántica del sitio.
* **CSS3:** Diseño responsivo y estilizado (estilo moderno y limpio).
* **JavaScript (ES6):** Lógica del sorteo, manipulación del DOM y validaciones.

##  Instalación y Uso

No necesitas instalar nada pesado. Para ejecutar el proyecto localmente:

1. Clona este repositorio o descarga el archivo ZIP.
2. Abre el archivo `index.html` en tu navegador preferido.
3. ¡Empieza a añadir a tus amigos y sortea!
